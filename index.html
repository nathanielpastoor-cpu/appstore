Installing (first time only)

  1. Tap Download on any app above.
  2. Android will warn you the file "can harm your device." That warning appears for every app not from the Play Store. Tap Download anyway.
  3. Open the downloaded file. You'll be asked to allow installs from your browser — tap Settings, enable it, then go back.
  4. Tap Install.

Updates install over the old version and keep your data, as long as the version number went up. If an update refuses to install, uninstall the old one first and reinstall — that means the signing key changed.

Automatic updates (optional)

Tired of the "can harm your device" warning, or want updates to arrive on their own? Install through Obtainium — a small open-source installer that pulls apps straight from this store's releases.

  1. Install Obtainium once (itself a one-time sideload — same steps as above).
  2. Back here, tap Obtainium on any app; it opens with everything pre-filled.
  3. Tap Add, then let it install. From then on, updates are automatic — no warning.

Obtainium itself is an APK download, so it shows the same one-time warning. Once it's in, nothing else does.
